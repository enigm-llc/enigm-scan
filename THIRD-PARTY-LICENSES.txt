Third-party software and data in Enigm Scan

Enigm Scan's own code is licensed under the PolyForm Noncommercial License
1.0.0 (LICENSE). The components below keep their own licenses. Engines are
separate programs run as subprocesses, pinned to exact versions and checked
against SHA-256 hashes before every run. When an engine is built, the license
files of every Python package it contains are copied into the app's
resources/engines/notices folder, with an inventory in
resources/engines/python-sbom.json.


Mobile Verification Toolkit (MVT) 2026.10.12
========================================================================
License: MVT License 1.1 (MPL 2.0 with an acceptable-use condition: devices
may only be analysed with the consent of their owner).
Source: https://github.com/mvt-project/mvt
Developed by Amnesty International's Security Lab. Packaged unchanged as the
mvt-engine engine by scripts/engines/build-mvt.py from the hash-locked list in
scripts/engines/engines.lock. Its LICENSE ships with the app.

pymobiledevice3 11.45.0
========================================================================
License: GPL-3.0 (LICENSES/GPL-3.0.txt).
Source: https://github.com/doronz88/pymobiledevice3
Packaged with scripts/engines/ios_entry.py as the ios-usb engine by
scripts/engines/build-ios.py from scripts/engines/pymobiledevice3.lock. The
complete corresponding source of that engine is ios_entry.py (GPL-3.0 or
later) plus the exact package versions in that lock file.
